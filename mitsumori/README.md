# 見積・発注 照合ツール

見積書と発注書(PDF・Excel・画像)を取引先ごとに入れて、型式・品名・数量・単位・単価・金額・納期の違いを探します。

- **社外に書類を出しません**(パソコンの中だけで動きます)。AIには送りません。過去の書類を覚えません。起動時と終了時、リセット時に、作業中の書類を全部消します。
- ✅ 確実に一致 = 文字入りPDF・Excelで全項目が一致 / ☑ 画像で一致 = 2種類の読み取りが一致(**似た文字 0とO・1とI は目で確認**)/ ❌ 違い / ⚠ 要確認。**✅以外は人が見る**。
- 使い方: 社ごとの枠に見積書と発注書を入れる → 「照合する」 → 結果を確認 → 「全部リセット」。

開発: `python mitsumori/server.py 8780` → http://127.0.0.1:8780/  /  試験: `python mitsumori/launcher.py --selftest out.txt`

## 試験(ダミー書類・242組)
`python mitsumori/tests/stress.py <作業フォルダ>` で、わざと間違いを入れた見積・発注書(数量・単価の1桁違い、型式の 0/O・1/I・ハイフン、カタカナ・漢字の違い、行の抜け・増え・重複、合計の誤り など)を作って照合し、**違いがあるのにOKと出した行(見逃し)**を数えます。
最新の結果: 見逃し 0 件 / 文字入りPDF・Excelは誤警報 0 件。画像は安全側に倒れ、読み取りに自信がない行は「要確認」になります。
**似た文字(0とO、1とI)の読み違いは、画像では完全には防げません。** 「☑ 画像で一致」の行は、確認ビューの赤枠で目で確認してください。

## 落ちるときの対策と、ログ(2026-11-26)
- 重い書類で落ちる報告を受け、次を入れた: ①読んだページ画像を圧縮して持つ ②同時に読む数を、パソコンの空きメモリで自動調整 ③メモリが足りないときは、待ってから、読めない旨を表示 ④1書類は先頭40ページまで(超えたら、読んでいないと明示) ⑤大きな写真は縮めて読む(向きも補正) ⑥1ページの失敗で書類全体を捨てない。
- ログ: 作業フォルダの1つ上(例: `C:\Users\<名前>\AppData\Local\mitsumori_check_log.txt`)。落ちた後に、このファイルを送ってもらえば、原因がわかる。書類の中身は書かない(ファイル名・秒数・メモリの空きだけ)。

## 「1回しか使えない」不具合の修正と、社ごとのリセット(2026-11-26)
- 症状: 1社を照合したあと、B社に書類を入れようとしても反応せず、リセットも押せない。
- 原因: 重い読み取りの最中は、画面が状態を聞いても、返事が数秒遅れる(測定: 最大3.6秒)。照合を始めた直後に出した古い問い合わせの返事(「読み取り中」)が、完了のあとに届き、画面が「読み取り中」のまま固まる。ボタンも枠も無効のまま、二度と更新されなかった。
- 直し: ①古い返事は捨てる(最新の問い合わせの返事だけを使う) ②見張りを、重ならない作りにした ③押した時点の最新の状態で判断する ④4秒ごとに裏の状態と合わせる。
- 追加: 各社の枠に「この社をリセット」ボタン。
- 試験: `tests/ui_race_test.js`(返事をランダムに0〜4秒遅らせて、照合→社ごとのリセットを3回くり返す)。使い方: アプリのサーバーを起動し、表示されたURLを引数にして `node ui_race_test.js <URL>`(Playwright が必要)。

## 見積 ⇔ 見積(客先に出した見積 と 仕入先の見積)(2026-11-26)
- 画面の上のタブで切り替える。**型式と品名だけ**を比べる。**単価・金額・合計・納期・単位は、違って当たり前なので、比べない**(読んでも比べない)。数量は「数量も比べる」を入れたときだけ比べる。
- 結果: ✅型式が一致 / ❌片方にだけある型式 / ⚠近い型式(1〜2文字の違い)・品名の違い・読み取りに自信がない。「確実なものだけ OK、それ以外は必ず人に見せる」ルールは、見積⇔発注と同じ。
- 書類が1枚ずつ(客先1・仕入先1)なら、見積番号が違っても、そのまま組にする。複数あるときは、型式の重なりで組を決める。
- **まだ本物の書類で試していない**(2026-11-26時点)。客先見積と仕入先見積は、表の形・列の並び・品名の書き方が違うはずなので、読み取りの調整が要る可能性が高い。見本(社名・金額は消してよい)が手に入ったら、調整する。
- 2つの使い方の書類は、別々に持つ(片方をリセットしても、もう片方の書類は消えない)。
- 試験: `tests/qq_compare_test.py`(型式の違いを入れた見本で、比べる部分だけを試す)/ `tests/ui_qq_test.js`(画面: タブの切り替え・照合・結果の保持・この社をリセット)。
