見積・発注 照合

書類はこのパソコンの中だけで処理します(外には送りません)
使い方: ①社ごとの枠に、客先に出した見積書と仕入先の見積書を入れる(ドラッグ、またはクリックして選ぶ。PDF・Excel・画像) → ②「照合する」 → ③結果を上から確認 → ④終わったら「この社をリセット」で次の社へ。
書類の中から、型番らしい文字列(英字と数字が混ざった4文字以上。例: B9565AW-T)を拾って、2枚の間で、同じか、違うかを見ます。表の形は、問いません(品名の欄の中に、型番が入っていても、拾います)。品名・数量・単価・金額・合計・納期・単位は、書類ごとに違って当たり前なので、比べません。
✅ 型番が一致 / ❌ 片方にだけある型番 / ⚠ 要確認=近い型番(1〜2文字の違い)・画像の読み取りに自信がない。✅以外は、必ず人が見てください。画像の書類は、似た文字(0とO、1とI)の読み違いを、完全には防げません。
使い方: ①社ごとの枠に、見積書と発注書を入れる(ドラッグ、またはクリックして選ぶ。PDF・Excel・画像) → ②「照合する」 → ③結果を上から確認 → ④終わったら「全部リセット」。
✅ 確実に一致=文字入りPDF・Excelで全項目が一致 / ☑ 画像で一致=画像を2種類の読み取りで確認。似た文字(0とO、1とI)の読み違いは完全には防げないので、画像を見て確認してください / ❌ 違い / ⚠ 要確認=読み取れない・自信がない。✅以外は、必ず人が見てください。

どういう基準で、判断していますか?(クリックで開く)

① 書類の読み方: 文字入りのPDFとExcelは、書いてある文字を、そのまま読みます。スキャン・写真は、2種類の読み取り(RapidOCR と Tesseract)で読み、2つが一致した行だけ「確実」とします。表の「見出し」(型式・数量・単価・金額など)の位置で、列を分けます。結果の下の「読み取った中身を見る」で、何を読んだかを確認できます。

② 判断の順番(見積 ⇔ 発注。何社・何枚まとめて入れても、同じ順番です): ①会社名(別の会社の書類どうしは、組にしません) → ②見積番号(発注書に書いてある見積番号が、見積の番号と一致すれば、いちばん強い根拠) → ③型番・品番(大文字小文字・ハイフン・空白の違いは同じとみなします。1〜2文字違いは「近い型番」として、人に確認) → ④品名(型番の無い行=送料など、最後の手がかり。ひもづけたあとは、型番が同じでも、品名がまるで違えば「要確認」にします) → ⑤数量(ひもづけたあと、違いを知らせます)。単価・金額は、見積と発注書で、違って当たり前なので、比べません(同じ型番が複数あるときの、ひもづけの手がかりにだけ、使います)。書類ごとではなく、「行」ごとに、ひもづけます。だから、見積2枚の中身が発注書1枚に収まっていても、見積1枚が発注書2枚に分かれていても、行はひもづきます。決まらないものは、黙って決めず、理由(見積番号・会社名・型番の重なり)を出して、人に回します。

③ 同じ型式の判定: 全角と半角、大文字と小文字、ハイフン、空白の違いは、同じとみなします。それ以外の違いは、1文字でも、違うとします。1〜2文字だけ違う型式は「近い型式」として、要確認に出します。

④ 比べる項目: 見積 ⇔ 発注は、型式・品名・数量(単価・金額・納期は、違って当たり前なので、比べません)。見積 ⇔ 見積は、表の「型式・品名」の列だけを読み(見出しの「数量・単価・金額」より左。宛先・日付・備考・納期・住所は読みません)、その中から、型番らしい文字列だけを比べます(英字と数字が混ざった4文字以上の文字列。電話番号・インボイス番号・「100V」のような単位つきの数字は、拾いません)。品名・数量・単価・金額・合計は、比べません。画像の書類は、2種類の読み取りの両方で見つかった型番だけを「確実」とし、片方だけなら「要確認」に出します。

⑤ 結果の意味: ✅=文字入りPDF・Excelで、全項目が一致 / ☑=画像で、型式・数量・金額が相手の書類と一致(目で確認) / ❌=違いがある(はっきり読めている。見積に無い品目が発注されたときも、ここ) / ⚠=読み取りに自信がない・近い型番・品名で判断した行 / 📋=発注されなかった品目(見積にあって、発注書に無い。数量減・見送りの可能性。エラーではありませんが、必ず知らせます) / 相手なし=組になる書類が無い。✅以外は、必ず人が見てください。
