# 入金確認ツール(Windows)

銀行の入出金リスト(PDF)を、文字として取り出して、**お客さんの名前で探し、日付・名義・金額の一覧と合計**を出す。
月に1回の入金確認の手間を減らすための、パソコンの中だけで動く小さなアプリ(外には何も送らない)。

## 使い方
1. 銀行からダウンロードした入出金リストの**CSVかPDF**を入れる(**CSVのほうが確実**。PDFは、文字を取り出すが、CSVは、そのままデータなので、読み違えがない)(3店舗ぶんを、まとめて入れてよい)→「読み込む」(文字を取り出して、データにする)。
2. 名前を入れて Enter。名義の書き方の違い(全角/半角・ひらがな/カタカナ・「(カ」「カ)」「株式会社」)は、そろえて探す。見つかった名義は、チェックで選べる(外すと、合計から外れる)。
3. 日付・名義・入金・出金の一覧と合計が出る。「一覧をコピー」でExcelに貼れる。各行から、元のPDFのページ(赤い枠)を見られる。
4. 次の月は、「**データを消して、次の月へ**」を押す(読み込んだPDFも読み取った中身も、全部消える。アプリを閉じたときも、消える)。

## 読み取りの確かさ
- 文字入りPDFは、**文字そのもの**を取り出す(読み間違いが、ない)。画像だけのPDFは、読めない(その旨を出す)。
- **残高のつながり**(前の残高 + 入金 − 出金 = 今の残高)で、全行を検算する。合わない行(読み落とし・読み違い)は、赤く出して、確認を促す。古い順・新しい順どちらの並びでも、検算できる。
- 入金と出金の列が、見出しと逆に読めていそうなときは、知らせる。名義が2行にまたがる行は、つなげて読む。行を読み取れなかったページは、ページ番号で知らせる。

## 未確認
- 実際の銀行のPDFの書式は、まだ見ていない(作った見本のPDFで、試験した)。見本が来たら、読み方を合わせる。
- 銀行の名義は、カタカナのことが多く、漢字(京セラ)では、見つからない。

## CSVについて(build 2)
- 文字コードは UTF-8 / Shift_JIS(CP932)を自動で判別。区切りは、カンマ・タブ・セミコロンを判別。
- 見出し行から列を探す: 「日付/取引日」「摘要/取引内容」「入金/お預り」「出金/お支払」「残高」。**金額が1列で「入出金区分」の列がある形**(区分に「入金」「出金」)も読める。
- PDFと同じく、残高の検算・名義の検索・合計・コピーができる。CSVには「元のページ」が無いので、「元の行を見る」で、CSVの行の文字を出す。
- PDFとCSVを、混ぜて入れてもよい(同じ取引を両方入れると、二重に数えるので、どちらか一方だけ入れる)。

## 残高の列が無いCSV・列の割り当て(build 3)
- **残高の列が無い明細**(入金額・出金額だけ)でも、検索・合計は、問題なく使える。残高の検算は、できないだけ。その場合は、**読み取った件数と入金・出金の合計**を出すので、銀行の画面の合計と、見比べて、読み取りを確かめる。
- 日付は `2026/11/01`・`2026-11-01`・`令和8年11月1日`・**`20261101`**(区切りなし)のどれでも読める。
- **名義(お客さんの名前)の列**は、見出し(摘要・取引内容・名義・振込人など)から探す。見つからない、または、ほとんど空(備考など)のときは、**文字がいちばん長い列を、推測**して、画面に知らせる。
- CSVの読み込み結果の下に、「**列の割り当て**」(日付・名義・入金・出金・残高が、どの列か)を出す。違っていれば、**選び直すと、その場で、読み直す**。

## お客さんを、まとめて探す(build 4)
- **登録のお客さん**: 名前の一覧を、アプリに覚えさせておく(30人でも)。保存先は、`%LOCALAPPDATA%\入金確認_設定\お客さんの一覧.json`。**「データを消して、次の月へ」では、消えない**(消すのは「登録を全部消す」だけ)。
- **「登録のお客さん全員の入金を出す」**: 読み込んだ入出金リストの中から、登録の全員の、日付・名義・入金・出金と、お客さん別の合計・全体の合計を、一度に出す。
- **登録していないお客さん**: その場で貼り付けて、同じように、まとめて出す。
- **保存・コピー**: 「**CSVで保存**」(デスクトップへ。Excelで開ける UTF-8 BOM つき。明細 + お客さん別の合計)、「一覧をコピー(Excelに貼れます)」、「お客さん別の合計だけコピー」。
- **名前の区切り方**(広く許す): ①1人ずつ**改行**(Excelの列の貼り付け)/ ②**タブ**(Excelの行の貼り付け)/ ③**読点(、)・カンマ・セミコロン** / ④**1行に並べるときは、空白**(半角・全角)でも。名前の中に空白がある人は、①か③で区切る(空白で並べると、2人に分かれる)。入力のたびに、「○人に分けました」と、分けた結果を、見せる。
- **別の書き方**は `=` でつなぐ(例: `京セラ=キョウセラ=ｷﾖｳｾﾗ`)。銀行の名義はカタカナなので、漢字の名前は、カタカナを足す。全角/半角・ひらがな/カタカナ・株式会社/(カ)の違いは、そろえて探す。
- 見つからなかったお客さん、名前が短くて他の人も拾いそうなお客さん、2人以上に当たった行は、画面で知らせる(全体の合計には、1回だけ入れる)。
- 試験: `tests/names_test.py`(区切り方の全部)。
